# CareNow Design System Skill

When designing or reviewing UI:

1. Read `DESIGN.md`.
2. Read `config/product.config.ts`.
3. Preserve the CareNow visual language.
4. Prefer existing tokens over new colors.
5. Prefer existing components over page-specific variants.
6. Keep card hierarchy consistent.
7. Use teal primarily for primary actions and active states.
8. Use blue for secondary informational emphasis.
9. Use amber only for warnings/prescription review.
10. Use red only for genuine critical/error states.

### Typography
Use Manrope.
- Display: bold, compact.
- Section heading: semibold.
- Body: regular.
- Metadata: smaller muted text.
- Price: semibold/bold.

### Surfaces
Use white cards on a very light cool background.
Borders should be subtle.
Shadows should communicate elevation, not decoration.

### Spacing
Use a 4px base.
Prefer 16 / 20 / 24 / 32 / 40 / 48px patterns.

### Status
Never rely only on color.
Pair status colors with text and/or icons.
