# CareNow Responsive Skill

Design from the reference layouts but make the implementation responsive.

## Breakpoints
Use the project's existing breakpoint system where possible. If none exists:
- mobile: < 640px
- tablet: 640–1023px
- desktop: >= 1024px

## Mobile
- 16px page gutter.
- Single-column primary content.
- Bottom navigation.
- Cards can become horizontal media rows.
- Filters become a drawer/sheet.
- Checkout should use a clear sticky primary action only if the project supports it safely.

## Desktop
- Max width 1280px.
- Use 2–4 column grids for marketplace listings.
- Keep search visible.
- Use side-by-side detail layouts when useful.
- Avoid excessive whitespace that pushes primary actions below the fold.

## Tablet
Collapse desktop grids before content becomes cramped.
