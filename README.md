# CareNow — Existing Impeccable + Claude Add-on

This package assumes Impeccable and Claude/Claude Code are already installed.

It does NOT contain installation/setup instructions.

Copy/merge these files into the existing CareNow prototype repository:

- `DESIGN.md`
- `REFERENCE_IMAGES.md`
- `CLAUDE_CARENOW_ADDENDUM.md`
- `.impeccable/context.md`
- `.impeccable/skills/*`
- `.claude/context.md`
- `.claude/skills/carenow-ui.md`
- `config/product.config.ts`
- `reference-images/*`

If your repository already has files with the same names, merge the CareNow-specific rules into the existing files instead of blindly overwriting them.

The two reference images are included so the design workflow has stable visual references.
