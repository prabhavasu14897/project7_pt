# CareNow — Standalone Website Asset Pack

These are standalone web-ready assets recreated/generated for the CareNow prototype.
They are NOT crops taken from the two original CareNow screen-collage screenshots.

Folders:
- brand — logo
- hero — welcome, dashboard and login hero imagery
- doctors — doctor profile photos
- pharmacies — pharmacy/provider logos and delivery partner
- medicines — medicine/product images
- labs — lab-test illustrations
- home-care — home-care service images
- health-packages — package/service imagery
- illustrations — prescription, verification and app illustrations
- extras — supporting healthcare imagery

Recommended usage:
- Use WebP files directly in the website.
- Keep the original filenames so they can map cleanly to the CareNow screens.
- SVG icons (search, cart, profile, etc.) should remain UI icons/components rather than image assets.
