# CareNow Claude Context

CareNow is a consumer healthcare marketplace.

Primary promise:
**Healthcare, delivered to your doorstep.**

Core categories:
Medicines, Lab Tests, Doctors, Home Care, Health Packages.

Primary navigation:
Home, Explore, Orders, Health, Profile.

Important distinction:
The product borrows the convenience and discovery pattern of food-delivery apps, but healthcare workflows must include prescription verification and provider-specific requirements.

Reference screens are generated visual references. Do not reproduce inaccurate medical/legal claims from the images.

All theme tokens, navigation, categories and static demo content should be controlled through:
`config/product.config.ts`.

The UI must be responsive and use shared components.
